# doukiryokou_fukushima

同期10人の福島・猪苗代 1泊2日旅行しおり。

## GitHub Pagesで公開

1. GitHubでこのリポジトリを開く
2. `Settings` → `Pages`
3. `Build and deployment` の Source を `Deploy from a branch`
4. Branch を `main` / `/(root)` にして `Save`
5. 数分後に表示される公開URLへアクセス

## ページ構成

メインページは `index.html` の1ファイル構成です。

- 9/5・9/6のタイムテーブル
- 予約済み情報
- 未確定の食事候補
- 那須でのプレゼント交換ルール
- 旅行前チェックリスト

スマホ表示を優先したデザインです。
